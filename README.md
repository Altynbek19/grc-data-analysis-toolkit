
# GRC Data Analysis Toolkit

**Course:** Cybersecurity Policy & Risk Management  
**Language:** Python

## Overview

This project introduces Python automation for Governance,
Risk, and Compliance (GRC) tasks.

## Part 1 — Organizational Profile Analyzer

- Identifies potentially applicable regulatory frameworks.
- Assesses governance, risk, and compliance maturity.
- Generates a readable GRC readiness report.

## Part 2 — CIA Triad Impact Classifier

- Classifies security incidents by confidentiality, integrity,
  and availability.
- Estimates severity based on the number of affected CIA properties.
- Prints a classification table for eight sample incidents.

## Requirements

- Python 3.10 or newer
- No third-party packages required

## How to Run

1. Clone or download this repository.
2. Open a terminal in the project folder.
3. Run:

   ```bash
   python3 grc_toolkit.py
   ```

## Customization

Replace the demonstration organization profile with the
company profile from Lab 1 before submission.
